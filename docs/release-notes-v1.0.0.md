# Nitro Control 1.0.0

The first public release turns the working ANV16-71 prototype into a reusable
Omarchy plugin for Acer Nitro owners.

## Highlights

- Clear fan controls in the Omarchy bar.
- Automatic recovery from abandoned Manual mode.
- Capability detection for other kernel-supported Nitro models.
- Exact-model policy for fallback drivers.
- One-click setup with one normal password prompt.
- Plain-language installation, compatibility, safety, and recovery guides.

## Important limitation

V1 does not enable raw embedded-controller writes on unknown models. Those
machines remain read-only until an owner completes the compatibility tests.
